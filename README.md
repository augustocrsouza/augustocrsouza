### 🛠️ Meu Laboratório Prático (Backend e Nuvem)
É importante entender como a informação é gerada. Para estudar isso, desenvolvi um projeto pessoal do zero (um sistema gerenciador de eventos). www.venttoapp.com.br

Foi o meu laboratório de testes onde pude aprender o básico sobre:
* **Criação de APIs:** Usando Java e Spring Boot para entender a origem dos dados.
* **Bancos de Dados:** Modelando e conectando um banco relacional (PostgreSQL).
* **Infraestrutura Básica:** Aprendendo a tirar o código do meu computador e colocar na nuvem (AWS), usando um pouco de Docker e GitHub Actions.
