# Olá, eu sou o Cesar 👋

**Engenheiro de Dados & Backend focado em arquitetura de software, infraestrutura na nuvem e automação de processos.** 
Construo soluções escaláveis unindo o ecossistema Java à engenharia de dados, sempre com foco em resolver problemas reais de negócio. 

*Construindo a arquitetura passo a passo.*

---

### 🏆 O que já entreguei

Desenvolvimento e arquitetura de ponta a ponta de soluções reais, saindo do ambiente de estudos para a nuvem:

*   🚀 **Arquitetura de SaaS do Zero:** Idealização e construção do backend do VenttoApp (plataforma de gestão de contratos e eventos) utilizando **Java e Spring Boot**.
*   ☁️ **Infraestrutura e Nuvem:** Estruturação de ambiente na **AWS** com separação de responsabilidades (EC2 para aplicação, RDS para banco de dados relacional PostgreSQL e S3 para armazenamento de estáticos).
*   ⚙️ **Cultura DevOps e Deploy:** Implementação de pipelines de CI/CD utilizando **GitHub Actions**, containerização com **Docker** e gestão de imagens no AWS ECR.
*   🤖 **Automação orientada a IA:** Engenharia de triagem com integrações via **Make** e **Webhooks**, conectando caixas de entrada ao LLM (Claude) para leitura de contexto e abertura automatizada de cards no **Jira**.
*   🏎️ **Engenharia de Dados:** Participação na construção de um Data Lakehouse para ingestão e armazenamento de dados de telemetria da Fórmula 1.
